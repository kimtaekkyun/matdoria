# 요구사항

최종 업데이트: 2026-11-13

## 목적

개인 맛집 지도를 만들어 링크로 공개합니다. 주 사용자는 본인과 지인이며, 일부 외부 공유도 가능합니다. 식당 목록은 정량 지표로 선별한 약 100곳입니다.

## 범위

### 포함

- 지역: 서울 (전국 확장은 추후)
- 지도 표시: 카카오맵 JavaScript SDK
- 식당 기준 키: 카카오 장소 ID (`place_id`)
- 선별 목록: 정량 지표 기반 점수 상위 100곳 (`Top 100`)
- 필터: 지표 조건 조합 (가변적). 여러 리스트 운용 가능
- 화면: PC 우선, 모바일 필수 지원 (반응형)
- 배포: Vercel, Next.js
- 갱신: 수동 (데이터 파일 재생성 후 재배포)

### 제외

- 네이버 지도, 네이버 검색 API
- 블로그 언급량 등 주관적 텍스트 기반 신호
- 업무추진비 결제 데이터 (justhere와 같은 방식이므로 제외)
- 본인 평가 (직접 별점, 태그)
- 리뷰 플랫폼 스크래핑 (망고플레이트, 캐치테이블 등)

### 보류

- 블루리본 서베이: 과거에는 제외했으나, 공개 데이터·재사용 권리·공식 제공 경로를 다시 확인한 뒤 도입 여부 결정 (scoring-strategy.md 참고)
- 서울미식 100선 등 외부 편집·기관 선정 목록: 공식 데이터와 이용 조건 확인 후 검토

## 기능 요구사항

1. 서울 식당 약 100곳을 카카오맵에 마커로 표시합니다.
2. 마커/리스트에서 장소를 선택하면 pin을 강조합니다. PC에서는 pin 옆 말풍선 상세를, 모바일에서는 dim 처리 없이 하단 리스트 영역을 상세 패널로 바꿔 표시합니다. `×`로 닫으면 목록을 복원합니다.
3. 상세에는 이름, 주소, 카카오/구글 지도 링크, 선정 근거, K Star/G Star 스냅샷을 표시합니다.
4. 검색과 source 탭으로 미쉐린, 서울미래유산, 착한가격업소, 모범음식점, 서울미식 100선, 백년가게 목록을 분리해 봅니다. 수집·매칭이 아직 끝나지 않은 탭은 준비 상태와 건수를 표시합니다.
5. `Matdoria's Pick`은 위 출처의 통합 목록에서 별도 큐레이션 조건을 적용한 결과를 표시합니다. 조건과 점수는 설정 파일로 관리하고, 근거를 상세 화면에 표시합니다.
6. 선택된 리스트에 맞춰 지도 마커와 장소 목록을 함께 갱신합니다.
7. 장소 목록에서 이름순, K/G Star순, K/G 리뷰·평가 수순으로 정렬합니다. 평점이 없는 장소는 해당 정렬에서 뒤에 둡니다.
8. 평점은 수집 시점의 정적 스냅샷입니다. 표기 형식은 `K Star 4.0 ★★★★★ (123)` / `G Star 4.0 ★★★★★ (123)`이며, 평점이 없으면 값/카운트를 비웁니다.

## 데이터 요구사항

1. 모든 식당은 카카오 장소 ID를 가져야 합니다. 매칭에 실패한 항목은 최종 데이터에서 제외합니다 (D-002).
2. 각 속성은 출처와 수집 날짜를 가져야 합니다.
3. 원본 데이터는 `data/raw/`에 보관하고 git에서 제외합니다.
4. 가공 결과는 `data/processed/`에 보관합니다.
5. 노트북에서 가중치와 필터를 바꿔 실험하고, 그 결과를 같은 파이프라인으로 재현할 수 있어야 합니다.

## 선별 기준 (현재 합의)

- 정량 지표만 사용합니다. 주관적 리뷰 텍스트는 사용하지 않습니다.
- 지표 후보: 미쉐린 등급 (D-007), 서울미래유산 선정과 개업연도 (D-008), 착한가격업소, 모범음식점 등 공공 지정 이력.
- 구별 상한은 두지 않습니다 (Top 100 자체만 고정).
